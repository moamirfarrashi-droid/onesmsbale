وان‌اس‌ام‌اس در بله | ۶۰ روز و ۳۶۰ پست
۰۷:۱۷ کارت تصویری، ۰۹:۱۷ آموزش، ۱۱:۱۷ نمونه کاربردی،
۱۳:۱۷ تمرین اجرایی، ۱۵:۱۷ نکته کوتاه، ۱۸:۱۷ سؤال روز.
ساعت‌ها به وقت تهران‌اند.

نصب از وب گیت‌هاب
۱. در خود بله به https://ble.ir/botfather برو و با /newbot یک بازو بساز.
   بازو را به کانال اصلی و یک کانال تست جدا اضافه کن و دسترسی انتشار بده.
۲. یک ریپازیتوری تازه بساز، مثلاً onesms-bale-bot. ZIP را Extract کن.
   همه فایل‌ها به‌جز bale-publish.yml را در صفحه اصلی ریپازیتوری با
   Add file > Upload files آپلود کن و Commit changes را بزن.
۳. با Add file > Create new file فایل زیر را بساز:
   .github/workflows/bale-publish.yml
   محتوای کامل bale-publish.yml را در این فایل کپی و Commit کن.
۴. از Settings > Secrets and variables > Actions > Secrets این سه سکرت
   را بساز:
   BALE_BOT_TOKEN = توکن بازوی بله
   BALE_CHANNEL_ID = شناسه عمومی کانال اصلی با @ یا شناسهٔ عددی بله
   BALE_TEST_CHANNEL_ID = شناسه عمومی کانال تست با @ یا شناسهٔ عددی بله
   برای کانال خصوصی از شناسهٔ عددی خود بله استفاده کن.
۵. از Actions > OneSMS Bale 60 Days > Run workflow برو.
   check اتصال و نوع کانال‌ها را بدون ارسال بررسی می‌کند.
   preview / day=1 / slot=0 متن هر شش پست را در لاگ نشان می‌دهد.
   test / day=1 / slot=0 شش پست را فقط به کانال تست می‌فرستد.
   اگر لاگ خطای دسترسی داد، مدیر بودن بازو در کانال و مجوز انتشار را چک کن.
۶. بعد از تست، از Settings > Secrets and variables > Actions > Variables:
   BALE_CAMPAIGN_START_DATE = تاریخ میلادی روز اول به وقت تهران (YYYY-MM-DD)
   ENABLE_BALE_POSTING = true
   برای یک روز اول کامل، تاریخی انتخاب کن که هنوز شروع نشده است.

پیگیری انتشار
• سؤال‌های روز با گزینه‌های شماره‌دار در یک پیام می‌آیند. اگر دیدگاه‌های
  کانال فعال باشند، مخاطب می‌تواند همان‌جا شماره گزینه‌اش را بنویسد.
• status آمار و شناسه پیام‌های امروز را در لاگ نشان می‌دهد.
• publish اجرای دستی صف است و تنها اولین پست سررسیدشده را در کانال اصلی
  می‌فرستد. سقف انتشار شش پست در روز است. تأخیر گیت‌هاب می‌تواند ساعت ارسال
  را جابه‌جا کند. بررسی صف در بازهٔ ۰۷:۰۰ تا ۱۹:۰۰ انجام می‌شود.
• فایل bale-state.json خودکار ساخته می‌شود و تاریخ
  شروع، شناسه کانال و ارسال‌های ثبت‌شده را نگه می‌دارد. فایل را پاک نکن.
• برای توقف موقت ENABLE_BALE_POSTING را false کن. برای ادامه آن را true کن.
  پست‌های سررسیدشده هنگام توقف، برای ادامه در صف باقی می‌مانند.
• اگر لاگ پیام pending داد، وضعیت همان پست را در کانال بررسی کن.
• اگر خطای همگام‌سازیِ سابقه دیدی، مجوز نوشتن Actions و قوانین شاخه را
  بررسی کن.

مستندات رسمی بازوی بله: https://docs.bale.ai/
